# 前端视觉检查（2026-09-09）

## 本轮修正验证

补充修复：重命名、项目选择、提示和预览四类遮罩共用主界面的 5px 外边距与 8px 圆角裁剪，实测四边坐标一致；弹窗容器同步为 8px 圆角。卡片内容底部增加留白，状态控件焦点描边向内绘制，保留键盘焦点提示且不越过卡片边界。桌面坐标断言和截图检查通过。

- 左右标题栏统一 52px，两种窗口宽度下内容均从 y=153 开始，顶部误差 0px。轨道标题文字 x=57 不再随窄窗口断点改变。
- 右侧信息字段与标题/画布左边线一致；备注和打开按钮均为 30px 高，顶部和底部误差 0px。
- 常用文字统一为 12px，轨道标题 14px、底部提示 11px；工具图标为本地 16×16、1.5px 描边 SVG，应用图标保留 24×24 PNG。
- 更多菜单挂在页面浮层，保留重命名轨道、重命名前缀及二次确认删除；实际桌面测试覆盖键盘打开/上下移动/Escape、取消确认、两个重命名、确认删除、菜单边界、滚动关闭、导入锁及原图节点复用。
- 13 项前端单元测试及现有真实 WebView2 集成检查通过。布局坐标断言通过 1280×820、980×640，像素密度 1、1.25、1.5 三档。像素密度使用 CDP 模拟，未切换 Windows 系统 DPI，也未测试跨不同 DPI 显示器移动窗口。
- 本地交付 `dist/ImageRail.exe`、`dist/frontend-normal.png` 和 `dist/frontend-compact.png`；截图使用合成测试图片。没有上传 GitHub。

初次检查本地工作台版本，使用真实 Release WebView2 和合成图片项目，覆盖 1280×820、980×640，以及单图/对比、信息面板打开状态。以下将可测量错位与视觉一致性改进分别说明；以下保留初次发现的问题，状态已按本轮修正更新。
